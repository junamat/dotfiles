# dotfiles-state

Generated by `dotfiles-snapshot`. Do not edit by hand; rerun the script.

## Restore on a fresh install

```bash
cd ~/.config/dotfiles-state
sudo pacman -S --needed - < packages/pacman-native.txt
yay -S --needed - < packages/pacman-aur.txt
awk '{print $1}' packages/flatpak.txt | xargs -r flatpak install -y flathub
awk '{print $1}' packages/pipx.txt | xargs -rn1 pipx install
awk '{print $1}' packages/cargo.txt | xargs -r cargo install
xargs -r npm install -g < packages/npm-global.txt
xargs -rn1 code --install-extension < packages/code-extensions.txt
awk '{print $1}' systemd/system-enabled.txt | xargs -r sudo systemctl enable
awk '{print $1}' systemd/user-enabled.txt | xargs -r systemctl --user enable
```

- `etc/` mirrors selected files from `/etc`; review and copy back with sudo.
- `system/etc-modified.txt` lists every `/etc` file changed from its package
  default (names only), as a checklist of what else was tweaked.
- `system/groups.txt`: `sudo usermod -aG <group> $USER` for each one missing.
- `system/kernel-cmdline.txt`: reference for the boot entry options.
